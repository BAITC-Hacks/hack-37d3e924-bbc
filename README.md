# Протокол совещания из аудио

Русская, казахская и смешанная речь → транскрипт с говорящими → поручения с источниками и сроками → саммари → ручная проверка → DOCX. Все модели самостоятельно развёрнуты; данные совещаний не передаются внешним облачным API.

## Текущее состояние

Дедлайн: 23.09.2026 18:00 GMT+5. В репозитории две отдельные реализации: [прототип «Хаттама»](prototypes/meeting-mvp/README.md) с интерфейсом Streamlit и [модуль ai/](ai/README.md) с контрактным `run_pipeline`. Прототип пока не вызывает этот интерфейс. В `backend/` и `frontend/` находятся только инструкции: общий FastAPI/React/SQLite-сценарий ещё не реализован.

На Windows проверены запуск интерфейса, сохранение и восстановление правок, экспорт и диаризация двух MP3 из `data/`. Полный сценарий с исходными моделями здесь заблокирован: отсутствуют веса ASR, а MLX LLM требует поддержанной среды Apple Silicon. Модели не заменялись. Тесты на синтетических данных не доказывают качество распознавания или извлечения поручений. Результаты ревью, исправления и оставшиеся задачи: [docs/CODE_REVIEW.md](docs/CODE_REVIEW.md).

## Воспроизводимость

Из корня репозитория в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\prototypes\meeting-mvp\setup.ps1
.\prototypes\meeting-mvp\start.cmd
```

Открыть http://127.0.0.1:8501. Установка по умолчанию не скачивает веса. Подготовка исходных моделей и полный запуск на macOS описаны в [инструкции прототипа](prototypes/meeting-mvp/README.md); настройка отдельного контрактного модуля — в [ai/README.md](ai/README.md).

Проверки из корня после подготовки окружения (без запуска моделей):

```powershell
.\prototypes\meeting-mvp\.venv\Scripts\python.exe -m pip install -r ai\requirements-base.txt
$env:PYTHONUTF8 = '1'
.\prototypes\meeting-mvp\.venv\Scripts\python.exe -m pytest ai\tests prototypes\meeting-mvp\tests -q
pwsh -NoProfile -File contracts/verify.ps1
```

`make run` / `make up` запускают этот же локальный прототип, `make verify` — оба набора тестов. Для них переменная `PYTHON` должна указывать на подготовленное окружение; Make необязателен на Windows. `.env.example` описывает предлагаемое общее приложение и не заменяет настройки отдельного прототипа. Root Compose пока нет.

Перед сдачей тимлид собирает от участников:

1. Точный commit, ОС, Python/Node, lockfiles/проверенные версии, GPU/драйвер/CUDA, RAM/VRAM/диск.
2. Команды установки и подготовки весов с revision, лицензиями и условиями доступа; секреты не коммитить.
3. Команды запуска API, frontend и отдельного worker; пути общего тома, SQLite и весов, конфигурацию без секретов.
4. Повторный запуск другим человеком из чистой копии по README; после подготовки — работа без внешних сервисов.
5. Команды тестов, frontend build, реальный сквозной пример, сохранение правки и DOCX, ссылки на доказательства.
6. Остановку процессов и GPU, сохранение/удаление данных, тарификацию диска после остановки.

Три короткие смоделированные записи минимум с двумя говорящими: сценарии и ожидания в docs/ACCEPTANCE.md. Синтетический JSON в contracts/examples/ не является замером моделей.

## Расходы и ограничения

Отдельные $50 GPU и $50 OpenAI API у каждого по сообщению тимлида. Общий баланс не подтверждён. Участник 1 проверяет сервис, остаток, тариф, карты, остановку и оплату хранения; начинает с минимально достаточного эксперимента. Дополнительные GPU — после измеренной потребности. OpenAI используется только для разработки без данных совещаний.

Полная приёмка RU/KZ/mixed с исходными моделями на машине запуска не пройдена. Локальные замеры диаризации приведены в инструкции прототипа; результаты автора на другой машине отмечены отдельно. Значимость README/воспроизводимости 25 из 100 известна из сообщения пользователя, ещё не сверена с DOCX в рамках этого ревью.
