# Протокол совещания из аудио

Русская, казахская и смешанная речь → транскрипт с говорящими → поручения с источниками и сроками → саммари → ручная проверка → DOCX. Все модели самостоятельно развёрнуты; данные совещаний не передаются внешним облачным API.

## Текущее состояние

В репозитории есть общий командный каркас, контракты, синтетическая фикстура и отдельный [прототип «Хаттама»](prototypes/meeting-mvp/README.md), добавленный в main. По его инструкции прототип рассчитан на macOS Apple Silicon и пока не реализует общий контракт из contracts/. При разрешении конфликта модели и приложение не запускались; заявленные автором результаты приведены в README прототипа. В data/ добавлены два DOCX и две аудиозаписи; их содержимое в рамках исправления Git-конфликта не изучалось. Дедлайн: 23.09.2026 18:00 GMT+5.

## Воспроизводимость

Инструкция запуска отдельного прототипа находится в [prototypes/meeting-mvp/README.md](prototypes/meeting-mvp/README.md). Общий FastAPI/React/worker-сценарий пока не подтверждён. Makefile из исходного набора не является командой запуска этого прототипа. Проверка контракта уже доступна: `pwsh -NoProfile -File contracts/verify.ps1` (PowerShell 7.5+). .env.example задаёт предлагаемые общие настройки; их поддержку участник 2 реализует в приложении. Перед сдачей тимлид собирает от участников:

1. Точный commit, ОС, Python/Node, lockfiles/проверенные версии, GPU/драйвер/CUDA, RAM/VRAM/диск.
2. Команды установки и подготовки весов с revision, лицензиями и условиями доступа; секреты не коммитить.
3. Команды запуска API, frontend и отдельного worker; пути общего тома, SQLite и весов, конфигурацию без секретов.
4. Повторный запуск другим человеком из чистой копии по README; после подготовки — работа без внешних сервисов.
5. Команды тестов, frontend build, реальный сквозной пример, сохранение правки и DOCX, ссылки на доказательства.
6. Остановку процессов и GPU, сохранение/удаление данных, тарификацию диска после остановки.

Три короткие смоделированные записи минимум с двумя говорящими: сценарии и ожидания в docs/ACCEPTANCE.md. Синтетический JSON в contracts/examples/ не является замером моделей.

## Расходы и ограничения

Отдельные $50 GPU и $50 OpenAI API у каждого по сообщению тимлида. Общий баланс не подтверждён. Участник 1 проверяет сервис, остаток, тариф, карты, остановку и оплату хранения; начинает с минимально достаточного эксперимента. Дополнительные GPU — после измеренной потребности. OpenAI используется только для разработки без данных совещаний.

Качество RU/KZ/mixed, доступность весов, скорость и память не измерены. Значимость README/воспроизводимости 25 из 100 известна из сообщения пользователя, ещё не сверена с DOCX.
