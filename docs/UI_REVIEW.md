# Проверка интерфейса — 23 сентября 2026

Проверена Windows-сборка React/FastAPI и сохранён Streamlit-прототип. Визуальные правила находятся в [DESIGN.md](../DESIGN.md).

## Изменения

- Боковая навигация с поиском совещаний и фильтрами статуса; единые цвета, типографика и состояния кнопок.
- Форма загрузки с выбором файла, обычными полями даты/времени и часовым поясом. Дата пустая до ввода пользователем; невозможные и неоднозначные значения отклоняются.
- Отдельные этапы загрузки, обработки и проверки. Тестовый результат явно обозначен.
- Поручения с исполнителем, сроком, источниками и ручной проверкой; переход к исходной реплике подсвечивает её и переносит фокус.
- Панель сохранения и экспорта. Несохранённые/некорректные правки блокируют DOCX; перед отменой изменений требуется подтверждение.
- Адаптация для узких экранов; мобильная панель действий находится в потоке страницы и не перекрывает последние поля.
- На узком экране список совещаний раскрывается отдельной кнопкой и сворачивается после выбора; форма доступна без прокрутки всей библиотеки.
- В Streamlit улучшены контраст, этапы, пояснения недоступных действий и диагностика моделей; оставлен один редактор источников поручения.

## Проверенная среда

Windows, Python 3.14.6, Node.js 24.18.0, зависимости из существующих lock/requirements-файлов. Новые зависимости интерфейса не добавлены. Общий запуск `scripts/manage.py run --profile fixture` поднимает API и отдельный worker; `Ctrl+C` проверен до освобождения порта и завершения обоих процессов.

Для браузерной проверки создан отдельный каталог `.local/ux-preview-*`. Использован сгенерированный WAV с тишиной и **явный профиль fixture**. Реальные записи и исходные материалы `data/` не открывались. Эти результаты не подтверждают качество моделей.
