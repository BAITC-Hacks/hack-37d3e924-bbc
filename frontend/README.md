# Интерфейс проверки протоколов

React + TypeScript, сборка Vite. Все запросы через `src/api/client.ts`; в production используется тот же origin, что у FastAPI. Внешние CDN, шрифты и API не нужны.

```bash
npm ci
npm run build
npm test
npm run lint
```

Backend раздаёт `dist/`. Для разработки: `npm run dev`; `/api` проксируется на `127.0.0.1:8000`. Типы соответствуют общим JSON-схемам, окончательная проверка выполняется сервером.

Интерфейс предупреждает об уходе с несохранёнными правками и не предлагает экспорт до сохранения. Конфликт версий не перезаписывает чужой результат. Весь текст совещания отображается через экранирование React, без raw HTML.
